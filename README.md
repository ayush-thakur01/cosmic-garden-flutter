 **🌸 Cosmic Garden – Flutter Generative Art App**



**An interactive Flutter application that creates glowing animated flowers**

**on screen taps using CustomPainter and AnimationController.**



 **✨ Features**

**- Tap to generate animated flowers**

**- Smooth sway and rotation animation**

**- Gradient petals with glow effect**

**- Procedural colors and sizes**



 **🛠️ Tech Stack**

**- Flutter**

**- Dart**

**- CustomPainter**

**- AnimationController**



**▶️ How to Run**

**```bash**

**flutter pub get**

**flutter run**
